---
description: how to run the real estate application
---

To run the project, you need to start both the backend and the frontend servers.

### 1. Start the Backend Server
1. Open a terminal.
2. Navigate to the `backend` directory.
3. Run the following command:
```powershell
npm start
```
> [!NOTE]
> The backend will run on `http://localhost:5000`.

### 2. Start the Frontend Server
1. Open a **new** terminal.
2. Navigate to the `landscape-client` directory.
3. Run the following command:
```powershell
npm run dev
```
> [!NOTE]
> The frontend will run on `http://localhost:5173`.

### 3. Access the Application
- **User Site**: Open [http://localhost:5173](http://localhost:5173) in your browser.
- **Admin Login**: Go to [http://localhost:5173/admin/login](http://localhost:5173/admin/login).
